# О проекте
Консольный архиватор, реализующий алгоритм Хаффмана — один из классических методов статистического сжатия данных без потерь. Программа позволяет сжимать и восстанавливать файлы произвольного формата (текст, изображения, аудио, бинарные данные).

# Структура
src/
├── HuffmanTree.c — ядро алгоритма: структуры дерева, обход, канонические коды и таблица кодов.
├── minHeap.c — минимальная куча: динамический массив, операции push/pop, просеивание и управление частотами узлов.
├── frequencyTree.c — конструктор дерева: построение оптимального бинарного дерева Хаффмана из кучи с элементами символ - частота.
├── fileReader.c — побайтовое чтение, сериализация заголовка, побитовая упаковка/распаковка и декодирование через обход дерева.
└── main.c — консольный интерфейс

tests/: содержит набор модульных, интеграционных и системных тестов.
  ├── testMinHeap/: проверка корректности операций push/pop, инвариантов кучи и edge-кейсов.
  ├── testHuffmanTree/: тесты структуры дерева, канонических кодов, поиска по таблице и дереву.
  ├── testFrequencyTree/: интеграционные тесты взаимодействия кучи и построения частотного дерева.
  └── testsIntegrationalAndSystem.c/: системные roundtrip-тесты на текстовых и бинарных файлах (.wav, .bmp, .bin, .txt).

ctest --output-on-failure

# Использование

## Сжатие файла
./main -c <input.txt> <compressed.huf>

## Восстановление файла
./main -d <compressed.huf> <output.txt>

## Справка
./main -h
