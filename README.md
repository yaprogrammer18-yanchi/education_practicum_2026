## О проекте
Консольный архиватор, реализующий алгоритм Хаффмана — один из классических методов статистического сжатия данных без потерь. Программа позволяет сжимать и восстанавливать файлы произвольного формата (текст, изображения, аудио, бинарные данные).

## Структура
<details>
src/
    HuffmanTree.c         Ядро алгоритма: структуры дерева, обход, генерация канонических кодов и таблица поиска
    minHeap.c             Приоритетная очередь: динамический массив, операции push/pop, просеивание и управление частотами
    frequencyTree.c       Построение дерева Хаффмана из кучи частот, обработка граничных случаев
    fileReader.c          Высокоуровневая логика: чтение файлов, сериализация заголовка, побитовое сжатие и разжатие
include/
    HuffmanTree.h         Заголовочный файл: объявления структур HuffNode, HuffmanTree, Cell и функций работы с деревом
    minHeap.h             Заголовочный файл: объявления операций с мин-кучей (создание, push, pop, поиск)
    frequencyTree.h       Заголовочный файл: функция построения частотного дерева
    fileReader.h          Заголовочный файл: функции сжатия/разжатия и работы с файлами
tests/
    testMinHeap/          Модульные тесты кучи: проверка инвариантов, операций push/pop
    testHuffmanTree/      Тесты дерева: канонические коды, поиск по таблице, обход
    testFrequencyTree/    Интеграционные тесты: взаимодействие кучи и построения дерева
    testsIntegrationalAndSystem.c  Системные roundtrip-тесты на текстовых и бинарных файлах
</details>

## Инструкция по сборке
git clone https://github.com/yaprogrammer18-yanchi/education_practicum_2026.git

cd education_practicum_2026

mkdir build && cd build

cmake ..

cmake --build .

ctest --output-on-failure

./main [аргументы]  - запуск исполняемого файла

## Использование

Сжатие файла
./main -c <input.txt> <compressed.huf>

Восстановление файла
./main -d <compressed.huf> <output.txt>

Справка
./main -h
